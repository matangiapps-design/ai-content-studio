# Run the free Blue Couture slideshow render

1. Add the two reference photos to this repository at:
   - `assets/blue_couture/reference-01-model-walking-blue-gown.jpg`
   - `assets/blue_couture/reference-02-model-seated-blue-look.jpg`
2. Open **Actions → Blue Couture Free Video Render → Run workflow**.
3. Choose 10 seconds and 1080×1920.
4. Download the `blue-couture-free-video` artifact from the completed run.

This workflow uses GitHub-hosted Ubuntu plus FFmpeg only. It does not use an AI video provider, paid API, secret key, or external media download. It produces a motion-photo edit with two slow zoom shots and a dissolve—not synthetic walking/seated movement. GitHub Actions usage limits and artifact retention depend on the account's plan.
