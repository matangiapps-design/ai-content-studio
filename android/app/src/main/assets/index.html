Connection & security

Studio settings

The token is kept in app memory only and is not saved to local storage. You must enter it again after restarting the app. Use HTTPS. Add https://appassets.androidplatform.net to the backend CORS_ORIGINS setting.

Connection checklist

1. Deploy the repository backend and frontend behind the same HTTPS domain.
2. Set STUDIO_API_TOKEN and CORS_ORIGINS=https://appassets.androidplatform.net on the backend.
3. Paste the domain and token above, then test connection.
4. Configure Gemini / WaveSpeed / Vertex credentials in the server Settings page before generating.
